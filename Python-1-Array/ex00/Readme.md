# Ex00 - BMI Calculation

## Sujet

Le but de cet exercice est de calculer l'indice de masse corporelle (BMI)
à partir de listes de hauteurs et de poids.

Fichier à rendre :

- `give_bmi.py`

## Données de départ

```python
height = [2.71, 1.15]
weight = [165.3, 38.4]
```

## Objectif

Calculer :

```python
weight / (height ** 2)
```

Et retourner le résultat dans une structure Python exploitable.

## Points importants

- Utiliser les listes en entrée.
- Penser à la formule de l'IMC.
- Vérifier la structure de sortie attendue.
- La seconde fonction doit renvoyer une liste de booléens selon une limite.
